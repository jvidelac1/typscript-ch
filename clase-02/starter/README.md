# Mi aplicación frontend

Aplicación armada con Vite y TypeScript.

## Cómo correrla

```bash
npm install
npm run dev
```

Para revisar los tipos:

```bash
npx tsc --noEmit
```

En esta etapa, ese comando muestra errores a propósito: son los ejercicios de `src/models/` y de `src/utils/mapearActividad.ts`. `npm run dev` anda igual.

## Modelos

Cuando termines los ejercicios, documentá acá las entidades que definiste: qué representa cada una, cómo se relacionan y por qué usaste `interface` o `type` en cada caso.
